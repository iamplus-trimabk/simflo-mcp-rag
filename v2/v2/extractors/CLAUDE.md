# Extractors Ecosystem

## Purpose
Content extraction and analysis ecosystem for various sources and formats.

## Components
- **code-extractors/**: React, Shadcn, Gluestack component extraction
- **language-extractors/**: TypeScript, Python code analysis
- **claude-code-extractor/**: AI-powered code analysis and documentation

## CLI Interface
```bash
extractors/code-extractors/extract.py --source /path/to/code --output /path/to/output
extractors/language-extractors/analyze.py --language typescript --source /path/to/src
extractors/claude-code-extractor/analyze.py --source /path/to/code --output /path/to/output
```
